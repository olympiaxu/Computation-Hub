Why a computation hub?

Computation connects ideas that might otherwise remain separate. Code offers a way to investigate how things work, test possibilities, and approach problems from various perspectives.

Computation Hub is built around that versatility. It brings together different applications of computational thinking while leaving room for unexpected connections between fields.

As the project grows, the goal is to create something people can learn from, contribute to, and use as a starting point for their own ideas.

Founder / Developer

Olympia Xu

"I created Computation Hub as an ongoing opportunity to experiment, learn, and build beyond the boundaries of a single discipline. I aim to turn ideas into practical projects that anyone can discover, explore, and build upon."
